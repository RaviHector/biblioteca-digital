## Ferramentas de IA Utilizadas

### 1. ChatGPT e Gemini Pro

**Uso Principal:** Análise de erros e resolução de problemas

Todos os integrantes da equipe fizeram uso extensivo do ChatGPT e Gemini Pro durante o desenvolvimento do projeto. Essas ferramentas foram fundamentais para:

- **Debugging:** Identificação e correção de bugs complexos
- **Análise de erros:** Compreensão de mensagens de erro obscuras
- **Resolução de problemas:** Encontrar soluções para desafios técnicos específicos
- **Consultas técnicas:** Esclarecimento de conceitos e melhores práticas

### 2. GPT-5 Mini (Integrado ao VS Code Copilot)

**Uso Principal:** Desenvolvimento de frontend e geração de código

O GPT-5 Mini, integrado ao VS Code através do GitHub Copilot, foi especialmente útil para:

- **Geração de páginas:** Criação rápida de componentes React com layout
- **Autocomplete inteligente:** Sugestões contextuais durante a codificação
- **Replicação de código:** Geração de códigos similares baseados em padrões existentes
- **Estilização:** Criação de styled-components e CSS

### 3. Claude 4 (Integrado ao GitHub Copilot)

**Uso Principal:** Assistência no desenvolvimento frontend e revisão de código

O Claude 4 foi utilizado principalmente para:

- **Layout e design:** Auxílio na implementação de interfaces responsivas
- **Code review:** Sugestões de melhorias no código
- **Documentação:** Geração de comentários e documentação
- **Refatoração:** Otimização e limpeza do código

## Desafios e Limitações Encontradas

### Compreensão Contextual Limitada

- **Falta de entendimento completo** do contexto do projeto
- **Sugestões inadequadas** que não se alinhavam com a arquitetura existente
- **Modificações indevidas** em partes do código que não deveriam ser alteradas

### Quebras de Funcionalidade

- **Introdução de bugs** em código funcional
- **Alterações não solicitadas** que causavam efeitos colaterais
- **Incompatibilidade** com padrões estabelecidos no projeto

### Necessidade de Supervisão Constante

- **Verificação obrigatória** de todas as mudanças sugeridas
- **Testes frequentes** da aplicação após cada modificação
- **Revisão manual** de código gerado automaticamente

---

## Estratégias de Mitigação Adotadas

### 1. Controle de Versão Rigoroso

Utilizamos o **Git** de forma sistemática para:

- **Commits frequentes** para preservar estados funcionais
- **Branches de desenvolvimento** para isolar mudanças arriscadas
- **Rollback fácil** quando mudanças causavam problemas
- **Histórico detalhado** de todas as modificações

### 2. Verificação Contínua

Implementamos um processo de:

- **Testes manuais** após cada mudança significativa
- **Code review** de todo código gerado por IA
- **Validação de funcionalidade** antes de aceitar sugestões

### 3. Uso Estratégico das Ferramentas

- **Segmentação de uso:** Diferentes IAs para diferentes propósitos
- **Prompts específicos:** Instruções claras sobre o que queríamos
- **Iteração gradual:** Pequenas mudanças por vez para facilitar controle

## Conclusões e Recomendações

### Principais Aprendizados

1. **As IAs são ferramentas poderosas de auxílio**, mas não substituem o conhecimento e julgamento humano
2. **Supervisão constante é fundamental** para evitar introdução de bugs
3. **O controle de versão é essencial** quando se trabalha com IAs
4. **Diferentes IAs têm pontos fortes distintos** e devem ser usadas estrategicamente

### Nossa Opinião Final

> **"No geral, as IAs auxiliam muito no desenvolvimento, principalmente para acelerar o processo, mas, na nossa opinião, ainda não são perfeitas e precisam ser tratadas como algo que te auxilia e não como algo que faz para você."**

As ferramentas de IA demonstraram ser **catalisadores valiosos** no processo de desenvolvimento, oferecendo:

- Aceleração significativa na codificação
- Insights valiosos para resolução de problemas
- Apoio na implementação de funcionalidades complexas

No entanto, é crucial manter uma **abordagem crítica e supervisionada**, utilizando essas ferramentas como **parceiras colaborativas** e não como substitutos para o pensamento crítico e a experiência humana.

### Recomendações para Futuros Projetos

1. **Estabelecer workflows claros** para integração de IA no desenvolvimento
2. **Investir em testes automatizados** para detectar regressões rapidamente
3. **Documentar padrões de uso** de diferentes ferramentas de IA
4. **Treinar a equipe** sobre boas práticas de uso de IA em desenvolvimento
5. **Manter controle de versão rigoroso** sempre que IAs estiverem envolvidas

## Reflexão sobre o Futuro

A experiência com IAs neste projeto nos mostrou que estamos vivenciando uma **revolução no desenvolvimento de software**. Embora as ferramentas ainda tenham limitações, o potencial de transformação é imenso.

À medida que essas tecnologias evoluem, acreditamos que a chave será encontrar o **equilíbrio perfeito** entre automação inteligente e supervisão humana, maximizando os benefícios enquanto mitigamos os riscos.

Este projeto serviu como um **laboratório valioso** para compreender como integrar efetivamente IA no ciclo de desenvolvimento, preparando-nos para um futuro onde essa colaboração será ainda mais ubíqua e sofisticada.
